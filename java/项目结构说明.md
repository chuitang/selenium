# Cookie管理工具 - 项目结构说明

## 项目概述

这是一个基于JDK 21的自动登录和Cookie管理工具，专为Windows环境设计。工具具备以下核心功能：

1. **自动登录网站**并保存Cookie到数据库
2. **定时检查Cookie有效性**，失效时自动刷新或重新登录
3. **智能Cookie刷新机制**，优先尝试携带旧Cookie获取新Cookie
4. **完整的数据库管理**，存储Cookie历史记录
5. **友好的命令行界面**，支持交互式和命令行模式

## 核心文件结构

### 主要Java类

#### 1. `CookieManagerApplication.java` - 主应用程序类
- **功能**: 程序入口点，提供命令行界面和交互模式
- **特性**: 
  - 支持交互式配置
  - 命令行参数处理
  - 服务生命周期管理
  - 用户友好的界面

#### 2. `CookieManager.java` - 核心管理类
- **功能**: 协调所有组件，实现主要业务逻辑
- **特性**:
  - 定时任务调度
  - Cookie生命周期管理
  - 异常处理和恢复
  - 服务状态监控

#### 3. `Config.java` - 配置管理类
- **功能**: 加载和管理所有配置参数
- **特性**:
  - 支持配置文件和Properties对象
  - 默认值管理
  - 配置验证
  - 多种配置源支持

#### 4. `CookieDatabase.java` - 数据库管理类
- **功能**: Cookie存储和检索
- **特性**:
  - H2数据库集成
  - 事务管理
  - 历史记录维护
  - 数据清理功能

#### 5. `AutoLogin.java` - 自动登录类
- **功能**: 使用Selenium WebDriver执行自动登录
- **特性**:
  - 智能元素定位
  - WebDriverManager集成
  - 反检测机制
  - 错误处理和重试

#### 6. `CookieValidator.java` - Cookie验证类
- **功能**: 验证Cookie有效性和尝试刷新
- **特性**:
  - HTTP客户端验证
  - 智能响应分析
  - Cookie刷新机制
  - 网络连通性测试

## 数据库设计

### cookies表结构
```sql
CREATE TABLE cookies (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    cookie_value TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    is_active BOOLEAN DEFAULT TRUE,
    website_url VARCHAR(500),
    notes TEXT
);
```

## 工作流程

### 1. 启动流程
```
应用启动 → 加载配置 → 初始化数据库 → 检查现有Cookie → 启动定时任务
```

### 2. Cookie检查流程
```
定时触发 → 获取当前Cookie → 验证有效性 → 尝试刷新 → 重新登录 → 保存新Cookie
```

### 3. 登录流程
```
启动WebDriver → 访问登录页 → 填写表单 → 提交登录 → 提取Cookie → 保存数据库
```

## 依赖关系

### 主要依赖

- **WebDriverManager 5.6.2** - 驱动管理
- **SLF4J + Logback** - 日志框架
- **JUnit 5** - 单元测试

### 系统要求
- **JDK 21+** - Java运行环境
- **Maven 3.6+** - 构建工具
- **Chrome浏览器** - Web自动化目标
- **Windows 10/11** - 操作系统

## 配置说明

### 关键配置项
```properties
# 网站信息
target.url=目标网站URL
login.url=登录页面URL
login.username=登录用户名
login.password=登录密码

# 元素选择器
login.username.field=用户名输入框
login.password.field=密码输入框
login.button.selector=登录按钮

# 检查设置
cookie.check.interval.minutes=检查间隔(分钟)
webdriver.headless=是否无头模式
```
